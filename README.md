# Р-26-1 Mini App — тестовая сборка для Bothost

Тестовая сборка запускает **Telegram-бота и Mini App одним Python-процессом** и использует одну SQLite-базу.

## Что уже подготовлено

- Telegram Web App авторизация;
- роли студент / администратор;
- тёмная мобильная тема;
- расписание;
- домашнее задание;
- оценки по предметам;
- средний балл;
- отдельный подсчёт Н / Б / О по каждому предмету;
- фильтры оценок за 30/90 дней и весь период;
- личная статистика;
- лента событий;
- админ-журнал оценок;
- выставление 2/3/4/5/Н/Б/О;
- исключение дополнительных аккаунтов из журнала без удаления их из базы;
- редактор расписания;
- кнопка «📱 Электронный дневник» в боте;
- единая SQLite-база для бота и Mini App.

## Настройки Bothost

- **Использовать домен:** включить;
- **Порт веб-приложения:** `3000`;
- **Кастомный домен:** например `r261`;
- **Главный файл:** `app.py`;
- **Собственный Dockerfile:** не включать.

## Переменные окружения

```env
BOT_TOKEN=токен_ТЕСТОВОГО_бота
ADMIN_IDS=твой_telegram_id
MINI_APP_URL=https://r261.bothost.tech
DEV_MODE=0
DEV_TELEGRAM_ID=0
DB_PATH=./data/bot.db
HOST=0.0.0.0
PORT=3000
TIMEZONE=Europe/Moscow
BOT_VERSION=2.1.1
HELP_USERNAME=@miravynvoida
```

`MINI_APP_URL` должен совпадать с HTTPS-адресом, который выдаст Bothost. Если выберешь другой домен — измени значение.

## Тестовая база

В `data/bot.db` лежит копия базы, прикреплённой для тестирования. Основная база не используется.

При первом запуске автоматически создаются таблицы Mini App:

- `journal_settings`
- `marks`
- `mini_events`

## Запуск

Bothost запускает:

```bash
python app.py
```

`app.py` одновременно поднимает веб-сервер на порту `3000` и запускает aiogram-бота через polling.

После запуска открой тестового бота и проверь кнопку `📱 Электронный дневник`.

## Важно

Это тестовая сборка. Основного бота и его базу пока не подключай. Сначала проверяем авторизацию, Mini App, оценки, расписание и синхронизацию на тестовом боте.
