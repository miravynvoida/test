# Р-26-1 Mini App — электронный дневник

Это первый рабочий каркас Mini App, подключённый к копии существующей SQLite-базы.

## Что уже есть

- Telegram WebApp авторизация;
- роли студент / администратор;
- тёмная мобильная тема;
- главная страница;
- расписание;
- домашнее задание;
- оценки по предметам;
- средний балл;
- отдельный подсчёт Н / Б / О по каждому предмету;
- фильтры оценок за 30/90 дней и весь период;
- личная статистика;
- лента событий;
- админ-журнал оценок;
- выставление 2/3/4/5/Н/Б/О;
- исключение студентов из журнала без удаления аккаунта;
- редактор расписания;
- единая SQLite-база с ботом.

## Запуск

1. Установить Python 3.11+.
2. `pip install -r requirements.txt`
3. Скопировать `.env.example` в `.env` и заполнить значения.
4. `python app.py`

Для реального Telegram Mini App сайт должен быть доступен по HTTPS. URL Mini App затем нужно указать в кнопке Web App у тестового бота.

## Тестовая БД

В `data/bot.db` лежит копия прикреплённой базы, поэтому оригинальную БД основного бота этот проект не изменяет.

При первом запуске автоматически создаются таблицы:
- `journal_settings`
- `marks`
- `mini_events`

## Важно

Это именно первый этап разработки, а не финальная версия. Архитектура уже рассчитана на дальнейшее добавление:
- полноценного редактора ДЗ;
- учебников и доп. материалов;
- управления студентами;
- уведомлений;
- расширенной статистики;
- периодов/семестров;
- посещаемости;
- связи с кнопкой Mini App внутри бота.

Для продакшена нужно использовать отдельную копию БД или резервную копию перед тестированием.
